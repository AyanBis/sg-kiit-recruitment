## Quick Start

```bash

npm install
npm run dev    # Development
npm run build  # Production build
npm start      # Production server
```

## Adding Images (Optional)

The site works perfectly without images, but you can add:

1. `/public/images/brand/sg-kiit-logo.png` - Official logo
2. `/public/images/hero/sg-kiit-hero.png` - Hero visual
3. `/public/images/events/*.jpg` - Event images
